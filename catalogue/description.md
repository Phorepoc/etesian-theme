The Etesian theme (the N9's look, re-envisioned) as a plain theme for the Symbian^3 UI: dark, with the Etesian colours and application icons.
After installing, open Themes and pick Etesian. Phorepoc OS images already carry it; this package is for other phones. It is a theme only (no shell).

The theme asks for the Fira Sans typeface (SIL OFL), which is not part of this package: where it is not installed, the system font is used.
